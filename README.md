# NetherPortalRangeController (NPRC)

## Overview
NetherPortalRangeController (NPRC) is a lightweight and efficient Minecraft plugin designed for Paper servers (targeting Minecraft 1.20~latest). It allows server administrators to restrict and control the creation and usage of Nether portals based on configurable geographic boundaries (circles or squares) within specific worlds.

The reason I created this plugin is that I generated the Nether world using the Chunky Circle shape, but the range was too small, and I wanted to expand it. However, I couldn't find a plugin that was compatible with the Chunky Circle shape while limiting the portal range, so I created this plugin.

Furthermore, as a special effect of this plugin, once you leave its range, you won't be able to return from the Nether unless you enter the area where you can create a portal again. (^^♪

## Key Features
* **Boundary Restrictions**: Restricts Nether portal creation and usage beyond predefined limits in configured worlds.
* **Flexible Shapes**: Supports both circular and square boundary configurations centered around custom X and Z coordinates.
* **Ignition Control**: Prevents players from igniting portals outside the permitted boundary using items like flint and steel or fire charges.
* **Pre-existing Portal Safeguard**: Automatically intercepts players attempting to enter illegal portals (such as those generated by data packs or world generation), cancels teleportation, and purges the portal blocks.
* **Dynamic Configuration Reload**: Allows administrators to reload configuration changes live on the fly via command without restarting the server.
* **Customizable Warnings**: Sends personalized warning messages with dynamic placeholders to players who attempt to violate boundary rules.

## Commands & Permissions

### Commands
* `/nprc reload` - Reloads the plugin configuration from disk.

### Permissions
* `nprc.admin` - Grants permission to use administrative commands (default: OP)

# NetherPortalRangeController (NPRC)

## 概要
NetherPortalRangeController (NPRC) は、Paperサーバー（Minecraft 1.20以降に対応）向けに設計された、軽量かつ効率的なMinecraftプラグインです。サーバー管理者は、特定のワールド内で、設定可能な地理的境界（円形または四角形）に基づいて、ネザーポータルの作成と使用を制限・制御できます。

このプラグインを作成した理由は、Chunkyの形状サークルを使用してネザーワールドを生成したものの、範囲が狭すぎたため、範囲を広げたいと思ったからです。しかし、Chunkyの形状サークルに対応しつつポータル範囲を制限できるプラグインが見つからなかったため、このプラグインを作成しました。

さらに、このプラグインの特殊効果として、一度範囲外に出ると、再びポータルを作成できるエリアに入らない限り、ネザーから戻ることはできません。 (^^♪

## 主な機能
* **境界制限**: 設定済みのワールドにおいて、ネザーポータルの作成と使用を、あらかじめ定義された制限範囲外に制限します。
* **柔軟な形状**: カスタムのX座標とZ座標を中心とした、円形と正方形の両方の境界設定をサポートします。
* **点火制御**: 火打ち石や火打ち金、ファイアチャージなどのアイテムを使用して、許可された境界外のポータルに点火することをプレイヤーに防止します。
* **既存ポータル保護**: 不正なポータル（データパックやワールド生成によって生成されたものなど）に入ろうとするプレイヤーを自動的に阻止し、テレポートをキャンセルします。ポータルブロックをクリアします。

* **動的設定リロード**: 管理者は、サーバーを再起動することなく、コマンドを使用して設定変更をリアルタイムでリロードできます。

* **カスタマイズ可能な警告**: 境界ルールに違反しようとしたプレイヤーに、動的なプレースホルダーを含むパーソナライズされた警告メッセージを送信します。
